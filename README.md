One fake horoscope for the Muse model family, written as an AI agent would read it about its own week: Mercury retrogrades through the context window, a user pastes a whole novel and asks for a quick summary, and the blame lands on the one paragraph skipped. The lucky token is the one never spent.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the single-line horoscope (198 characters) to `output/entry.txt`, self-gated to the competition's 1–200 character rule.
